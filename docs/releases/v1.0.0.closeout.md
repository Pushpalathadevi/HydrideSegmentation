## Remaining gaps

- The installer is not Authenticode-signed. Windows may show an
  unknown-publisher warning until a signing certificate and release signing
  pipeline are configured.
- Large validated trained checkpoints remain separately managed local
  artifacts by design; the base installer provides the conventional workflow
  and model registry/workspace infrastructure without embedding those binaries.

Unrelated user-owned book-chapter work and generated browser/output files were
kept outside the release commits.
