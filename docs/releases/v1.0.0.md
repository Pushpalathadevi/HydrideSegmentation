# MicroSeg v1.0.0 Release Notes

Release date: 2026-08-05

MicroSeg v1.0.0 is the first stable release of the local-first microstructural
segmentation platform. Hydride segmentation is the validated initial workflow;
the registry, pipeline, reporting, and correction contracts remain designed for
additional microstructural feature families.

## Release highlights

- Qt desktop workflow for single-image and recursive batch inference, review,
  correction, quantification, project resume, and complete scientific exports.
- Intranet web workflow for colleagues who need browser access without a local
  Python installation.
- Conventional and registered ML inference using common model metadata and
  CPU-safe runtime behavior.
- Fn analysis, physical calibration support, indexed/color correction exports,
  and machine-readable run provenance.
- One downloadable Windows setup executable that installs the desktop GUI and
  CLI companion without requiring administrator privileges.
- A writable `%LOCALAPPDATA%\MicroSeg\workspace` for logs, outputs, local model
  overlays, and user-installed checkpoints.
- Correct web readiness reporting in both startup-preload and on-demand model
  loading modes.

## Windows installation

1. Download `MicroSegDesktop_1.0.0_offline_setup.exe`.
2. Verify its SHA-256 value against `MicroSegDesktop_1.0.0_release.json`.
3. Run the installer. The default target is the current user's local Programs
   directory and does not require administrator rights.
4. Launch **MicroSeg Desktop** from the Start menu.
5. Use **File → Open Sample** and run **Hydride Conventional** for the first
   smoke test.

The setup file is offline: normal installation and conventional inference do
not need network access. Trained checkpoint files are managed separately so
deployment owners can control validated model binaries and provenance.

## Upgrade and compatibility notes

- Existing source-checkout commands and entry points remain available.
- Correction schema `microseg.correction.v1` and project schema
  `microseg.project.v1` remain supported.
- Local registry overlays and checkpoint binaries in the installed runtime
  workspace are preserved when canonical defaults are refreshed.
- Version discovery is available through `microseg-cli --version` and the
  packaged `MicroSegCLI.exe --version` command.

## Validation evidence

The release gate requires all of the following before publication:

- full CPU repository test suite;
- strict phase gate and registry validation;
- web API and real-browser smoke checks;
- Qt offscreen desktop smoke checks;
- packaged desktop and packaged CLI smoke checks;
- silent installer install, installed-app smoke, and uninstall verification;
- SHA-256 release metadata for the final setup executable;
- Sphinx HTML documentation build.

The final machine-readable closeout is recorded in
`docs/releases/v1.0.0.report.json`.

## Known limitations

- The installer is not Authenticode-signed in v1.0.0. Windows may display an
  unknown publisher warning.
- The base installer does not embed large trained model checkpoints. Deployment
  owners should install validated checkpoints through the local model workflow.
- Web deployment remains local/intranet-oriented; cloud hosting is not a v1.0.0
  target.

For the complete change history, see the top-level `CHANGELOG.md`.
