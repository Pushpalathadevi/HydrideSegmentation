# MicroSeg v2.0.0 Release Notes

Release date: 2026-09-27

MicroSeg 2.0.0 adds the **Hydride Connectivity Index (HCI)**, a new scientific measurement of how
far segmented hydrides link into long connected paths. It is on by default in the browser
application, available from the CLI and Python, and documented with typeset theory. This is a
major release: every web result now carries an additional measurement block, an extra report page
and new views, and the default output of a run therefore changes. Segmentation, area fraction and
Fn are unchanged.

## Why a new index

Area fraction says how much hydride there is and Fn says which way it points. Neither says whether
hydrides join into continuous paths, which is what separates harmless isolated platelets from a
through-wall network. The intern prototype of an HCI was audited and tested on a new
constant-area-fraction benchmark. It rose with hydride amount, returned 0 for fully connected
networks, and changed under rotation and transposition. It was therefore replaced by formulation
`hci.v1` (owner decision, 2026-09-27).

## What HCI v1 computes

- Hydride components are linked across matrix gaps up to δ; the links are synthetic bridges that
  add no area.
- The connectivity C(δ) is the area-weighted fraction of the reference length covered by each
  linked cluster's hydride.
- HCI is the mean of C(δ) over 0 … δ_max. It is reported radially (through-wall),
  circumferentially and isotropically, and lies in (0, 1].
- Reported alongside it:
  - the critical linking distance δ½ (µm);
  - the connectivity length ξ;
  - an RHCP-type path continuity Π;
  - skeleton topology with the exact identity N_E = β + 2C − 2μ and the network closure κ.
- δ_max defaults to one fifth of the smallest hydride accepted after clean-up (owner decision). A
  median-based automatic rule and a fixed value are offered. **Use a fixed δ_max to compare
  specimens**: an automatic value differs from image to image, as shown on the benchmark.

## Changes

### Added

- Library `src/microseg/evaluation/continuity/` with:
  - `analyze_continuity()`;
  - typed configuration and a result contract (`microseg.hci_result.v1`);
  - exact single linkage via the distance-transform gap graph and Kruskal;
  - the exact integral;
  - path continuity;
  - skeleton topology with thickness-scaled junction collapse;
  - overlays;
  - a batch runner.
- The web UI gains:
  - section **5. Connectivity (HCI)**, ticked by default, with the δ_max mode, an optional pixel
    size and an optional radial reference length;
  - an HCI results panel;
  - four views: clusters with red synthetic bridges, the connectivity curve, topology, and the
    weakest radial path;
  - an HCI page in the PDF report and a *Connectivity* sheet in the XLSX workbook;
  - `hci` in the JSON and the ZIP bundle.
- Web Help gains a full HCI section rendered with KaTeX, with a concept diagram and the algorithm
  flow sheet.
- CLI: `python scripts/microseg_cli.py hci --mask <file|folder> [--pixel-size-um a]
  [--max-bridge-distance d]`, configured by `configs/hci.default.yml`.
- Constant-area-fraction synthetic benchmark `test_data/hci_synthetic_v1/`: 203 masks with exact
  ground truth, generated by `scripts/generate_hci_synthetic_benchmark.py`.
- Evidence scripts:
  - `scripts/hci_candidate_study.py`, comparing the prototype and the candidates;
  - `scripts/hci_benchmark_evaluation.py`, evaluating the production library;
  - `scripts/hci_real_image_study.py`, covering the intern report's micrographs.
- Documentation:
  - `docs/hci_theory.md`, with proofs, the algorithm and complexity;
  - `docs/hci_user_guide.md`;
  - `docs/hci_specification.md`;

### Changed

- Web results include an `hci` block and `timing.hci_seconds`. Runs take longer: about 1 s for a
  1 megapixel mask and about 8 s at 2048 × 2048. Untick the option to skip it.
- The detailed PDF report has three pages when the HCI is enabled.

## Validation

- On the constant-area-fraction benchmark with a fixed δ_max of 10 µm, HCI v1 orders every family
  correctly in every replicate. Exact symmetries hold, resolution changes stay within 2 %, and
  segmentation noise changes the value by ≤ 1.8 %. Boundary roughness changes it by 5.2 %,
  against a 5 % target.
- Topology matches the ground truth exactly, and the identity residual is 0 on all benchmark masks
  and on the report's real masks.
- On the intern report's 25, 70 and 200 ppm masks:
  - circumferential HCI rises 0.155 → 0.182 → 0.261;
  - radial HCI stays ≤ 0.06;
  - δ½ falls 88 → 51 → 24 µm.

  Area fraction also rises across this series, so it cannot by itself separate amount from
  connectivity.
- Tests: `tests/test_phase37_hci_synthetic_benchmark.py`, `tests/test_phase38_hci_core.py` and
  `tests/test_phase38_hci_interfaces.py`.

## Known limitations

- The HCI is experimental until the field-data validation and property correlation are done.
- The desktop (Qt) application does not yet show the HCI; the library, CLI and web do.
- Path continuity dominates the runtime (about 6 s at 2048²).
- 2D sections only; clusters touching the border are truncated, and this is flagged.

## Upgrade notes

- `hydride-segmentation==2.0.0`. There are no new dependencies.
- Integrations that parse the web JSON gain an `hci` key; existing keys are unchanged.
- To reproduce 1.2.0 output exactly, submit `hci_enabled=false`.
