3. Conventional settings
The conventional method has no trained model behind it. It boosts local contrast (CLAHE), thresholds each pixel against its neighbourhood, then cleans up the result with morphology. It is fast, fully deterministic, and easy to explain, but you usually have to tune it per imaging condition. Start with the defaults and change one setting at a time. Read the full guide.

4. Quantification
Fn is the radial hydride fraction — the share of hydrides oriented radially rather than circumferentially. Each detected hydride is measured for its angle from the horizontal; those at or above the threshold below are counted as radial. Fn is reported two ways: by count (how many hydrides qualify) and length-weighted (what fraction of total hydride length qualifies). The length-weighted value is usually the more meaningful of the two, because one long radial hydride matters more than several short ones. Read the full explanation.

    Radial hydride fraction (Fn)

    - Length-weighted
    - Count-based

    Both numbers are fractions between 0 and 1. Length-weighted is the share of total hydride length that is radial, and is usually the number to report. Count-based is the share of individual hydrides that are radial, which is more sensitive to how many small features the segmentation picked up — raise the minimum feature size if noise is inflating it. Always state the angle threshold you used.
